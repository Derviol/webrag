# crawler — 网页采集

## 职责

- 对接搜索引擎 API（Bing / Tavily / 博查等）获取候选 URL；
- 抓取候选网页 HTML；
- 调度与限速、失败重试、robots 合规、反爬规避。

## 所属角色

- 爬虫开发（#2，2 人）：
  - A：搜索 API 适配层 + 候选 URL 整理；
  - B：抓取、限速、重试与异常处理。

## 接口约定

- 输入：查询词 query → 输出：候选 URL 列表（含标题、摘要）；
- 输入：URL → 输出：原始 HTML（交给 parser）。

## 验收标准

- [ ] 单条 query 稳定返回 N 条可抓取候选；
- [ ] 限速策略下不被目标站封禁；
- [ ] 明确声明 robots / 版权合规策略。

# docs — 项目文档中心

## 职责

- 集中管理项目文档：架构设计、接口契约、部署、开发指南、评测报告；
- 文档与代码同步维护，接口变更必须同步更新对应文档。

## 所属角色

- 项目协调 / 架构（分工表 #1）负责编写与维护；
- 各模块负责人补充本模块设计细节（也可直接写在对应模块 README.md）。

## 文档清单

| 文档 | 内容 | 状态 |
| --- | --- | --- |
| ../README.md | 项目总览、系统流程、协作规范、分工、里程碑 | 初稿 |

| quickstart.md | 本地开发快速开始（命令） | 规划 |

| CHANGELOG.md | 变更记录（协作记录，无 Git 场景即提交历史） | 使用中 |

## 约定

- 接口字段变更 = 破坏性变更，需同步更新 api.md 并全链路联调；
- 每个里程碑结束，评测/进度报告归档到本目录。
